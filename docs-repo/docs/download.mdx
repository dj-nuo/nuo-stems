# Download NUO-STEMS 4

NUO-STEMS 4 is available for download on https://nuo-stems.com

Changelog is available [here](/docs/changelog).

:::info NUO-STEMS 4.1.0
**4.1.0** is a stable application release with **Serato integration in alpha**. Use the stable release when installing or updating; you do not need the Alpha update channel to use Serato integration in 4.1.0.

The 4.1.0 release notes are prepared in the [changelog](/docs/changelog). Check the download website for the currently available installers.

The main installer includes all four modes, including Serato (alpha). There is no separate Serato installer or additional download. Generating Serato stems requires an active license or eligible Patreon access; the extraction utility is free to use.
:::

## System Requirements

### GPU Acceleration

For optimal performance with GPU acceleration:

- **Windows**: NVIDIA GPU with 4GB or more VRAM or any GPU that supports DirectX 12 (FL 12.0 or higher)
- **macOS**: Apple Silicon (M1/M2/M3 or later)

GPU acceleration is optional - NUO-STEMS 4 will work on CPU as well, though processing will be slower.

:::tip
All users who purchased NUO-STEMS 3 **after 1 November 2025 will automatically get a free upgrade** to NUO-STEMS 4. Just install NUO-STEMS 4 and your license will be activated automatically on the same computer where you have NUO-STEMS 3 installed.
:::
