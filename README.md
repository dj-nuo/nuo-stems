# NUO-STEMS

NUO-STEMS is a desktop app that separates tracks into vocals, drums, bass, and other instruments for use in Traktor, Serato, and DAWs.

- [Product website and downloads](https://nuo-stems.com/)
- [Documentation and blog](https://docs.nuo-stems.com/)

## Bugs and support

To report a bug or ask for help, see [Contact & Support](https://docs.nuo-stems.com/docs/contact-support/) or join the [Discord community](https://discord.gg/dfpk9FbvJE).

The documentation used to live in this repository. Its history is kept here; the current source is maintained elsewhere.
